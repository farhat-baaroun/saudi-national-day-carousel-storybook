# Saudi National Day Carousel

Stories load the published **UMD** from [npm](https://www.npmjs.com/package/saudi-national-day-carousel) via jsDelivr or unpkg — the same URLs a host page would use.

- jsDelivr: `https://cdn.jsdelivr.net/npm/saudi-national-day-carousel@1.1.0/dist/saudi-national-day-carousel.umd.js`
- unpkg: `https://unpkg.com/saudi-national-day-carousel@1.1.0/dist/saudi-national-day-carousel.umd.js`

Use the **Locale** toolbar to switch `lang` on the wrapping page. Stories also pass `locale` into `mount()` so the bundle remounts when you switch Arabic (RTL) and English (LTR).

**Portal template** drops the hero into a home-page shell inspired by [dev-dga-templates](https://github.com/DevDhaif/dev-dga-templates) (independent, not affiliated with the DGA).

## Options

Two motion variants and three asset sets. Options 2–4 share the same six values (heritage → support → ambition → generosity → kindness → vision). Option 1 keeps its own mosaic / scatter / field copy.

| Story | Motion | Assets |
| --- | --- | --- |
| Option 1 — Figures | No stagger | `option1/*` only |
| Option 2 — Photo deck | Staggered deck + arrows | `slides/*.png` |
| Option 3 — Pattern slides | No stagger | `slides_patterns/*.svg` |
| Option 4 — Pattern deck | Staggered deck + arrows | `slides_patterns/*.svg` |

Paired files: `vision.png` ↔ `vision.svg`, and the same for the other five values.

## Where it runs

The carousel is **client-side only**. A Laravel, ASP.NET, Django, or Odoo route can still serve it: render a sized empty host in the page, then call `mount()` in the browser. It does not SSR or hydrate server HTML.

| Host | How |
| --- | --- |
| React / Next.js | ESM component, or `dynamic(..., { ssr: false })` |
| Vue / Nuxt | `onMounted` + `mount()`, wrap in `<ClientOnly>` on Nuxt |
| Angular | `AfterViewInit` + `mount()`, `OnDestroy` + `unmount()` |
| Laravel, .NET, Rails, PHP | Blade / Razor host `div` + CDN script |
| Odoo Website | QWeb host + frontend asset, not QWeb server render |

```js
SaudiNationalDayCarousel.mount("#hero", {
  option: "option3",
  option3: [{ title: { ar: "عِزّنا", en: "Our pride" }, coloredTitle: { ar: "برؤيتنا", en: "in our vision" } }],
});

SaudiNationalDayCarousel.mount("#hero", (defaults) => ({
  ...defaults,
  option: "option2",
  option2: defaults.option2.slice(0, 3),
}));
```

Full recipes live in the [package README](https://github.com/farhat-baaroun/saudi-national-day-carousel#client-side-only-csr).
