# Saudi National Day Carousel

Stories load the published **UMD** from [npm](https://www.npmjs.com/package/saudi-national-day-carousel) via jsDelivr or unpkg — the same URLs a host page would use.

- jsDelivr: `https://cdn.jsdelivr.net/npm/saudi-national-day-carousel@1.0.0/dist/saudi-national-day-carousel.umd.js`
- unpkg: `https://unpkg.com/saudi-national-day-carousel@1.0.0/dist/saudi-national-day-carousel.umd.js`

Use **Fit Lab** to resize the parent, flip RTL/LTR, and tune motion. Compact peek appears around `390×760`. Switch **UMD source** to compare CDNs.
