# Saudi National Day Carousel

This Storybook repo loads the **UMD widget** from the sibling `saudi-national-day-carousel` workspace package — the same file a host page would pull from npm or a CDN.

1. From the workspace root, `npm run build` writes `packages/carousel/dist/saudi-national-day-carousel.umd.js`
2. Storybook serves that file at `/umd/...` (Local bundle)
3. After `npm publish` in the carousel package, switch **UMD source** to jsDelivr or unpkg

Use **Fit Lab** to resize the parent, flip RTL/LTR, and tune motion. Compact peek appears around `390×760`.
